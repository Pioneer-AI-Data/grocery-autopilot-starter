# Meal Library

> The planner's deck. Tags drive the variety rules; keep every field filled. Start with the ten dinners your family already eats.

## Card format

```
### Meal name
- protein: chicken | beef | pork | fish | veg
- cuisine: (Mexican, Italian, American, ...)
- effort: 15 | 30 | 45 (hands-on minutes)
- tier: easy | normal | project | crockpot
- healthy: yes/no (veg count: N)
- season: any | summer | winter
- last served: YYYY-MM-DD
- ingredients: item (store), item (store), ...
- picky path: what the picky eater gets
```
